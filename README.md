# 面试准备与技术学习

这个仓库用于积累真实面试复盘、按主题整理的面试题、系统学习笔记和学习资料。面试题回答可以链接到对应学习笔记，避免同一知识点在多处重复维护。

## 目录导航

```text
interview-prep/
├── README.md
├── 公司面试问题/                 # 按公司和岗位记录真实面试过程
│   └── template.md
├── 面经/                         # 可复用的面试问题与回答，按主题分类
│   ├── go/
│   ├── 数据库/{mysql,redis}/
│   ├── agent/
│   ├── 基础知识/{计算机网络,操作系统,算法}/
│   ├── 分布式系统/
│   ├── 云原生/{kubernetes,docker,prometheus}/
│   ├── 消息队列/
│   ├── rpc/
│   └── 系统设计/
├── 学习材料/                     # 系统学习笔记与原始学习资料
│   ├── go/
│   ├── databases/{mysql,redis}/
│   ├── agent/
│   ├── cloud-native/
│   ├── computer-science/
│   └── ...
└── projects/                     # 项目介绍、技术决策和难点复盘
```

## 归档方式

真实面试过程记录在 `公司面试问题/`；可复用的题目与回答放在 `面经/主题/`；系统知识笔记和参考资料放在 `学习材料/主题/`；项目讲解和技术复盘放在 `projects/`。

同一知识点只维护一份主题题解。真实面经中引用该题解，并补充当场回答和复盘。
